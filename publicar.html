Colocar o SAP Atlas online.

Guia para os ficheiros entregues. Publicação manual no Netlify, sem terminal e sem compilação.

Antes de começar

Precisa do ZIP atualizado, de um navegador e de uma conta Netlify para gerir as versões. Este projeto é um site estático: os ficheiros HTML, CSS e JavaScript já estão prontos.

O botão «Entrar no Atlas» abre explorer.html. O mapa usa dados incluídos no pacote. Esta versão não tem login, servidor SAP, base de dados de utilizadores ou sincronização entre pessoas. Publicar o site não instala recursos cloud nem um sistema SAP.

1. Extrair o ZIP

No Windows, clique com o botão direito em SAP-Atlas.zip → Extrair Tudo… → Extrair. Abra a pasta extraída.

Procure a pasta que contém diretamente index.html. É essa pasta que vai publicar. Não envie a pasta exterior se o HTML estiver dentro de outra pasta.

pasta a publicar/

  landing.css

Mantenha os restantes ficheiros do pacote. Os nomes e a relação entre pastas devem ficar iguais.

2. Testar os ficheiros antes de enviar

Faça duplo clique em index.html. Deve aparecer a página inicial com «Do ecossistema à arquitetura». Clique em Explorar arquitetura. Deve abrir o mapa claro com ícones.

Abra HANA, clique numa ligação numerada e confirme os detalhes. Use Ligações, Inventário e Comparar clouds. Se faltar algo, não publique ainda: confirme que extraiu todo o pacote.

Os vídeos do hero e os links documentais precisam de Internet. Se o vídeo falhar, a página mantém um fundo de cor. O som está desligado até o ativar.

3. Abrir o serviço de publicação

Abra Netlify Drop. Entre na sua conta ou crie uma conta para manter o projeto sob a sua gestão.

Arraste a pasta do passo 1 para a zona de envio. Aguarde a conclusão e abra o endereço HTTPS atribuído ao projeto. A publicação manual envia os ficheiros já preparados; não precisa de preencher um comando de build.

Resultado: a página inicial abre num endereço do projeto Netlify. Esse é o endereço para partilhar, depois de confirmar a visibilidade.

Procedimento: documentação oficial de publicação manual · consultada em 08/10/2026.

4. Confirmar que está acessível a outras pessoas

Abra o endereço numa janela privada, sem sessão Netlify. Confirme que a página inicial e /explorer.html abrem. Se aparecer um pedido de acesso, reveja a visibilidade do projeto no painel Netlify; algumas equipas configuram projetos privados por defeito.

Só partilhe o endereço quando este teste corresponder ao acesso que pretende dar.

5. Verificar a publicação

6. Usar um domínio próprio, se quiser

No projeto Netlify, abra a gestão de domínios e adicione o domínio que já controla. Siga as instruções DNS apresentadas para esse domínio. Copie os valores mostrados no painel para o seu fornecedor de DNS; não use valores de exemplo como se fossem os seus.

Depois da propagação DNS e da emissão do certificado, repita o teste do passo 5 no domínio próprio.

Guia oficial de domínio e DNS.

7. Publicar uma atualização

Extraia a nova versão completa. Abra o mesmo projeto no painel Netlify e a sua área de deploys. Use a zona de envio manual desse projeto para carregar a pasta atualizada. Depois, repita a verificação.

Guarde os ZIPs anteriores com a data. Assim mantém uma cópia identificável de cada versão e consegue voltar a enviar uma versão anterior.

Se algo não funcionar

ProblemaO que fazer
Página não encontradaVerifique se index.html está diretamente na pasta enviada.
«Entrar» não abre o mapaConfirme a presença de explorer.html na mesma pasta.
Sem estilos ou íconesVolte a enviar o pacote completo, incluindo friendly.css e technical.js.
Mapa vazioConfirme technical-data.js. Para referências, confirme reference-data.js. Ambos devem estar junto ao HTML.
Continua a versão antigaConfirme o deploy do mesmo projeto. Atualize com Ctrl + F5 e teste numa janela privada.
Vídeo sem imagemO vídeo é servido pelo URL externo do componente fornecido. Verifique a ligação e os bloqueios do navegador; o fundo de cor continua disponível.
Login ou erro de acessoConfirme as definições de visibilidade e proteção do projeto no Netlify.

Ficheiros do projeto e informação pública

Ao publicar esta pasta, disponibiliza a aplicação e os dados incluídos nela. Para esta versão, mantenha apenas os ficheiros do pacote final; não adicione credenciais, chaves cloud, transcrições privadas ou ficheiros de configuração reais de uma empresa.

Este guia explica como publicar. Não significa que uma publicação tenha sido efetuada por mim.

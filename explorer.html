Selecione um bloco para consultar função, condições de utilização, configuração e fontes. Abra grupos para explorar as partes e vizinhos externos.

As setas têm uma ação definida: «aloja» segue do host para o software, «chama» do cliente para o serviço, «grava» do escritor para o destino. A direção de uma ação não implica que os dados só possam circular num sentido.

Nos diagramas SAP importados, a direção e os rótulos são os do draw.io fornecido. Rótulos ausentes e ligações não resolvidas ficam assinalados.
